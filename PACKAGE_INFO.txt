🚀 QUICK START (15-30 MINUTES)
═══════════════════════════════════════════════════════════════

1. READ FIRST: docs/DEPLOYMENT_CHECKLIST_FINAL.md
   
2. Configure external services in backend/.env.production:
   • SMTP credentials (email)
   • SMS provider (Twilio recommended)
   • Payment gateway (Xendit/Stripe)
   • KYC provider (Sumsub/Onfido)

3. Set up SSL:
   sudo certbot --nginx -d yourdomain.com -d api.yourdomain.com

4. Deploy:
   sudo ./deployment/deploy.sh

5. Done! 🎉
