# Add these dependencies to backend/package.json

## Production Dependencies:
"nanoid": "^3.3.7"

## Why nanoid?
- HIGH-009: Fix predictable transaction IDs
- Generates cryptographically secure random IDs
- URL-safe, compact (21 characters default)
- Collision-resistant (similar to UUID v4 but shorter)
- Much faster than UUID

## Installation:
npm install nanoid

## Usage Examples:
import { nanoid } from 'nanoid';

const transactionId = `TXN-${nanoid(21)}`; // e.g., TXN-V1StGXR8_Z5jdHi6B-myT
const orderId = `ORD-${nanoid()}`; // Default 21 chars
const reference = nanoid(32); // Custom length for extra security
